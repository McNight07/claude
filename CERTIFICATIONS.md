# CompTIA Certifications → Relevant Job Roles

A reference mapping of CompTIA's certifications (source: [comptia.org/en-us/certifications](https://www.comptia.org/en-us/certifications/#all)) to the job roles each one is most relevant for. Certifications are grouped by CompTIA's official career pathways, followed by the stackable certifications that combine multiple base certs into a single credential.

## Core Skills Pathway

| Certification | Description | Relevant Job Roles |
|---|---|---|
| **CompTIA Tech+** (formerly ITF+) | Entry-level introduction to computing, networks, software, data, and security fundamentals. | IT Support Trainee, Help Desk Technician (entry), Career-changer into IT |
| **CompTIA A+** | Core skills for supporting and troubleshooting hardware, software, mobile devices, and OS. | IT Support Specialist, Help Desk Technician, Desktop Support Administrator, Field Service Technician, Technical Support Specialist |
| **CompTIA Network+** | Foundational networking concepts, infrastructure, and troubleshooting. | Network Administrator, Network Support Specialist, Systems Administrator, Junior Network Engineer, Help Desk Technician (Tier 2) |
| **CompTIA Security+** | Baseline cybersecurity skills for risk management, threats, and secure network architecture. | Security Administrator, Systems Administrator, Security Specialist, Security Engineer (entry), SOC Analyst (Tier 1), Network Administrator |

## Infrastructure Pathway

| Certification | Description | Relevant Job Roles |
|---|---|---|
| **CompTIA Server+** | Server hardware/software administration, virtualization, storage, and security. | Server Administrator, Data Center Technician, Systems Administrator, IT Infrastructure Technician |
| **CompTIA Linux+** | Managing, securing, and troubleshooting Linux systems across cloud and hybrid environments. | Linux Administrator, Systems Administrator, Cloud Engineer, DevOps Engineer, Site Reliability Engineer |
| **CompTIA Cloud+** | Designing, securing, and optimizing multi-cloud infrastructure. | Cloud Engineer, Cloud Administrator, Systems Administrator, Network Administrator, Cloud Specialist |
| **CompTIA Cloud Essentials+** | Business-oriented understanding of cloud adoption, ROI, and risk. | IT Manager, Business Analyst, Cloud Business Analyst, Non-technical decision-makers evaluating cloud strategy |

## Cybersecurity Pathway

| Certification | Description | Relevant Job Roles |
|---|---|---|
| **CompTIA CySA+** | Behavioral analytics for vulnerability management, threat detection, and incident response. | SOC Analyst, Security Analyst, Threat Intelligence Analyst, Incident Responder, Vulnerability Analyst |
| **CompTIA PenTest+** | Hands-on offensive security skills across the full penetration-testing lifecycle. | Penetration Tester, Vulnerability Tester, Security Consultant, Ethical Hacker, Cybersecurity Specialist |
| **CompTIA SecurityX** (formerly CASP+) | Advanced, hands-on enterprise security architecture and engineering. | Security Architect, Senior Security Engineer, Security Consultant, Cybersecurity Manager |
| **CompTIA SecAI+** | Skills for securing and governing AI systems and models. | AI Security Specialist, Security Engineer (AI/ML systems), Security Analyst |

## Stackable Certifications

Stackable certifications combine two or more base certifications (all must be Continuing Education / CE active) into a single higher-level credential.

| Stackable Certification | Requires | Relevant Job Roles |
|---|---|---|
| **CompTIA Secure Infrastructure Specialist** | A+ + Network+ + Security+ | IT Support Specialist with security responsibilities, Systems Administrator, Junior Security Administrator |
| **CompTIA Cloud Admin Professional** | Network+ + Cloud+ | Cloud Administrator, Systems Administrator, Network/Cloud Engineer |
| **CompTIA Network Infrastructure Professional** | Network+ + Server+ | Network Administrator, Infrastructure Engineer, Data Center Technician |
| **CompTIA Linux Network Professional** | Network+ + Linux+ | Linux Network Administrator, Systems Engineer |
| **CompTIA Secure Cloud Professional** | Security+ + Cloud+ | Cloud Security Engineer, Cloud Administrator with security focus |
| **CompTIA Security Analytics Professional** | Security+ + CySA+ | Security Analyst, SOC Analyst (Tier 2), Threat Analyst |
| **CompTIA Network Vulnerability Assessment Professional** | Security+ + PenTest+ | Vulnerability Assessment Analyst, Junior Penetration Tester |
| **CompTIA Network Security Professional** | Security+ + PenTest+ + CySA+ | Security Engineer, Network Security Analyst |
| **CompTIA Security Analytics Expert** | Security+ + CySA+ + SecurityX | Senior Security Analyst, Security Operations Lead |
| **CompTIA Security Infrastructure Expert** | Security+ + CySA+ + PenTest+ + SecurityX | Security Architect, Principal Security Engineer, Cybersecurity Manager |

*Compiled from CompTIA's published certification pathways and stackable certification program. Certification names and requirements are subject to change by CompTIA — verify current details at [comptia.org](https://www.comptia.org/en-us/certifications/#all).*
